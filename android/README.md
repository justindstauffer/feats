# Android App (Feats)

This folder contains the Android client for Feats.

## Current Status
- Initial project scaffold created.
- Jetpack Compose shell with bottom-tab navigation.
- Auth/session state scaffold and API client foundation.

## Setup
1. Open `android/Feats` in Android Studio (latest stable).
2. Let Gradle sync.
3. Configure local API base URL in `BuildConfig` via build type if needed.
4. Run app on emulator/device with Android 10+ (API 29+).

## Notes
- This is milestone 1 scaffolding.
- Feature parity work (feed details, groups, reactions/comments, websocket, push) is in progress.
